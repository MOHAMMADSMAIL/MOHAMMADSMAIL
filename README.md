01 — The signal behind the noise


I am an AI & Data Science undergraduate at Zarqa University, expected to graduate in 2027. I build practical systems that move from raw data to usable interfaces: machine-learning experiments, NLP prototypes, forecasting tools, and full-stack applications.

My approach is simple: understand the problem deeply, build the smallest useful version, measure what matters, then keep improving. I am currently developing a Weather Intelligence Platform that combines data, prediction, and a clear user experience.
